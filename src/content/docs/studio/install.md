Jabali Studio is available for Windows and macOS. Get the installer from the [Jabali Studio download page](https://jabali.ai/jabalistudio), then follow the steps for your operating system.

## System requirements

| Requirement      | Minimum                    |
| ---------------- | -------------------------- |
| Windows          | Windows 10 or later        |
| Mac              | macOS 12 or later          |
| Memory (RAM)     | 4 GB (8 GB recommended)    |
| Disk space       | 500 MB free                |

## Install on Windows

1. Download the `.exe` installer from the [Jabali Studio download page](https://jabali.ai/jabalistudio).
2. Run the installer and follow the on-screen steps.
3. Launch Jabali Studio.

:::note[Windows pop-up]
If you see a Windows pop-up when you launch Jabali Studio, first click **More info**, then click **Run anyway**.
:::

## Install on Mac

1. Download the `.dmg` file from the [Jabali Studio download page](https://jabali.ai/jabalistudio).
2. Drag the app to your **Applications** folder.
