After you sign in, Jabali Studio lists the games in your account that you can open and edit, including games you started on Jabali Web or FriendJam. The home screen shows your **Recent Projects**. To see them all, click **Your Projects** in the sidebar or **View all**.

![The Your Projects library in Jabali Studio showing a grid of games with posters and genres](../../../assets/studio/your-projects-library.webp)

## Open a game

1. From the start screen, click any game in your library.
2. Your game opens in Studio. The first time you open a game on a computer, Studio downloads its files, which can take a moment.

![A project opened in Jabali Studio, with Bali's project summary on the left and the game preview on the right](../../../assets/studio/project-opened-in-studio.webp)

Icons on a project card tell you more:

| Icon                  | Meaning                                                              |
| --------------------- | -------------------------------------------------------------------- |
| Cloud with an arrow   | The game isn't downloaded to this computer yet.                      |
| Archive box           | The game is archived and read-only. See [Archive a project](#archive-a-project). |

:::tip[Don't see your latest game?]
Go back to the home screen to reload your library, and check that you're signed in with the same account you used to create the game. See the [FAQ](/docs/studio/faq/#game-access-and-sync) for more help.
:::

## Open a FriendJam game

You can bring games you made on FriendJam into Jabali Studio and keep building them with Bali, including assets, code and publishing.

1. Click the FriendJam game in your library.
2. Studio asks: *"This is a FriendJam game. Do you want to open it in Jabali Studio?"*
3. Click **Proceed with Jabali Studio** to import it, or **Keep in FriendJam** to leave it where it is.

:::caution
Once you import a game into Jabali Studio, you can't edit it in FriendJam anymore.
:::

To check how the game looks on FriendJam, choose **FriendJam Mobile** in the preview's **Dimensions** menu.

## Archive a project

Archiving keeps your library focused on what you're working on now. An archived game is read-only, but nothing is deleted, and you can unarchive it at any time. Inactive projects may also be archived automatically.

- **To archive:** click the **⋮** menu on the project card and choose **Archive project**, or switch the project to **Archived** in **Project Settings → Game Settings**. Studio asks you to confirm. A project needs to be in sync with your account before you can archive it.
- **To unarchive:** click **⋮** and choose **Unarchive project**.

When you open an archived game, Studio asks what you'd like to do:

- **Open read-only** to look around without making changes. A **Read-Only** badge reminds you.
- **Unarchive and edit** to make it editable again.
- **Return home** to go back.

## Free up disk space

Games you've opened are stored on your computer. To reclaim space, remove the local copy of a game you're not working on. The game stays in your account, and Studio downloads it again the next time you open it.

1. Click the **⋮** menu on the project card and choose **Delete local content**. This option is only available for games that are downloaded to this computer.
2. Review the **Delete local project contents** dialog. It shows whether the game is in sync with your account and whether you have local changes or history that hasn't been uploaded yet.
3. Choose an option:
   - **Delete local contents** if everything is in sync.
   - If you have changes that aren't saved or uploaded yet, choose the option that saves and uploads them before deleting, such as **Commit and push, then delete**, so you don't lose any work.
   - **Cancel** to keep the files.

:::caution
Deleting local contents without uploading your changes first permanently discards those changes.
:::
