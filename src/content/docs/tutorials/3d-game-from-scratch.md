Build a 3D game where the player jumps between platforms to escape lava that keeps rising. Part 1 builds the core loop. Part 2 adds the scenery and finishes the game.

## Part 1: Build the core loop

<div class="video-embed"><iframe src="https://www.youtube-nocookie.com/embed/y5oDck88fhY" title="Video: Build a 3D game from scratch, part 1" loading="lazy" allow="accelerometer; clipboard-write; encrypted-media; gyroscope; picture-in-picture; web-share" referrerpolicy="strict-origin-when-cross-origin" allowfullscreen></iframe></div>

1. [01:01](https://youtu.be/y5oDck88fhY?t=61) Describe a 3D concept: jump between platforms to escape lava that keeps rising.
2. [01:17](https://youtu.be/y5oDck88fhY?t=77) Studio sees it's a 3D game and shortlists templates. The example picks a third-person action template.
3. [03:31](https://youtu.be/y5oDck88fhY?t=211) Studio adapts the template to your prompt.
4. [06:14](https://youtu.be/y5oDck88fhY?t=374) The first result already has rising lava and a character that can jump.
5. [07:40](https://youtu.be/y5oDck88fhY?t=460) Bali offers to generate textures and audio for the lava, platforms, safe zone, music and sound effects.
6. [11:29](https://youtu.be/y5oDck88fhY?t=689) Fix broken controls by saying exactly which keys you want: arrow keys to move, mouse to turn the camera.
7. [15:41](https://youtu.be/y5oDck88fhY?t=941) When code errors appear, ask Bali to debug them and check the preview logs.
8. [18:29](https://youtu.be/y5oDck88fhY?t=1109) Make the lava rise each time the player reaches a new platform, so there's no going back.
9. [18:45](https://youtu.be/y5oDck88fhY?t=1125) Add slow-moving platforms.
10. [25:47](https://youtu.be/y5oDck88fhY?t=1547) Make the rising lava obvious with an animation and an on-screen notice.
11. [28:11](https://youtu.be/y5oDck88fhY?t=1691) Ask Bali to make sure the generated assets are actually in the game.
12. [31:02](https://youtu.be/y5oDck88fhY?t=1862) Adjust asset transparency and brightness to fit the look.
13. [36:51](https://youtu.be/y5oDck88fhY?t=2211) Add power-ups that lower the lava, raise jumps and add points.

## Part 2: Scenery and finishing touches

1. [03:17](https://youtu.be/BMA3t_YWwik?t=197) Add buildings around the track so the rising lava is easy to see.
2. [06:53](https://youtu.be/BMA3t_YWwik?t=413) Generate building textures that fit the post-apocalyptic theme.
3. [12:03](https://youtu.be/BMA3t_YWwik?t=723) Review the finished loop.
4. [16:46](https://youtu.be/BMA3t_YWwik?t=1006) Replace the skybox with a more seamless one.
