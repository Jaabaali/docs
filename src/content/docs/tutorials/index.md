Each tutorial walks you through a real project step by step, with screenshots, so you can follow along without watching. Every step links to the matching moment in the video, and the full video is on each page if you'd rather watch.

New to Jabali? Start with the cave arcade series, or follow the [Beginner path](/docs/start/beginner/), which pairs these tutorials with the guides you need along the way.

## Cave arcade game

A six-part series for beginners. You build one lane-based arcade game, where a spelunker dodges monsters underground, and each part adds to it. No coding needed.

| Part | What you'll do | Video length |
| --- | --- | --- |
| [1. Make your first game](/docs/tutorials/first-game/) | Go from an idea to a playable game with Bali | 2 min |
| [2. Customize and polish a game](/docs/tutorials/customize-a-game/) | Change visuals, add an enemy and tune difficulty by asking Bali | 16 min |
| [3. Publish your game](/docs/tutorials/publish-a-game/) | Share a playable link to your game | 2 min |
| [4. Add collectibles and scoring](/docs/tutorials/collectibles-and-scoring/) | Build a new mechanic with art, sound and logic | 15 min |
| [5. Generate characters and art](/docs/tutorials/characters-and-art/) | Create a new player character and poster | 9 min |
| [6. Upload your own art](/docs/tutorials/upload-your-own-art/) | Add your own artwork and have Bali wire it in | 4 min |

## Projects

Three standalone projects for the [Advanced path](/docs/start/advanced/). Each stands on its own, so take them in any order. The web and 3D projects start from scratch. The Godot project starts from a tower defense game you've already made with Bali.

| Project | What you'll do | Video length |
| --- | --- | --- |
| [Build a web game from scratch](/docs/tutorials/web-game-from-scratch/) | Make a Phaser alchemy game without a template and keep its content in a data file | 50 min |
| [Fix and tune a Godot game](/docs/tutorials/fix-and-tune-a-godot-game/) | Use the Assets, Layouts and Scripts tabs to fix and rebalance a tower defense game | 13 min |
| [Build a 3D game from scratch](/docs/tutorials/3d-game-from-scratch/) | Make a 3D platformer with rising lava, textures, power-ups and a skybox | 59 min |

The tutorials were recorded on an earlier version of Jabali Studio. Where the app has changed, a **Current app** note explains the difference.

For longer sessions on design, prompting and polish, watch the [AI Masterclass playlist](https://www.youtube.com/playlist?list=PL9XiOGQzkhZJK_nzUKbdnPPsigPkBZ1_V) on YouTube.
