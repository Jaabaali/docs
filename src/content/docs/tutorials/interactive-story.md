In this tutorial, you'll use the Jabali Discord bot to create a branching narrative game, where the player's choices shape the outcome of the story. Jabali takes you from a simple idea to a fully interactive, AI-generated game using natural-language prompts.

**Before you start:** [join the Jabali Discord and register](/docs/discord/).

## Step 1: Start your game with a prompt

In a channel where the Jabali bot is active, type `/make`. When prompted, enter a descriptive prompt such as:

> A curious teenager discovers a hidden elevator in their school that leads to alternate realities. Each choice brings them deeper into a surreal, ever-shifting storyline.

Then set the genre to **Branching Interactive Story**.

![The /make command in Discord with a prompt and the genre set to Branching Interactive Story](../../../assets/tutorials/interactive-story-make-command.png)

Jabali creates a Discord thread for your game, analyzes the prompt and creates your game seed.

## Step 2: Review and edit the game seed

The [game seed](/docs/discord/game-seed/) includes core parameters such as:

- **Visual style** (e.g. hand-drawn, pixel art)
- **Theme** (e.g. mystery, coming of age)

![The game seed generated in a Discord thread, with Create Concept and Edit Seed buttons](../../../assets/tutorials/interactive-story-game-seed.png)

You can edit the seed at any time in Discord. Click **Create Concept** to continue.

## Step 3: Accept or regenerate the game concept

Jabali generates a game concept that includes:

- A game title
- A story summary
- An AI-generated poster

![The generated game concept "Elevator of Endless Choices" with Create Game and Regenerate Concept buttons](../../../assets/tutorials/interactive-story-concept.png)

If you like it, click **Create Game**. If not, click **Regenerate Concept**.

## Step 4: Define your player and characters

Use [character prompts](/docs/discord/asset-prompts/#character-prompts) to define the player and key NPCs.

![A generated character profile with personality, abilities, portrait and Edit Data and Edit Prompt buttons](../../../assets/tutorials/interactive-story-character.png)

## Step 5: Edit scenes

Next, Jabali generates the locations where your story unfolds. Edit a location's prompt to regenerate its image.

![A generated story location, "The Enchanted Portal", with its description, image and Edit Prompt button](../../../assets/tutorials/interactive-story-locations.png)
