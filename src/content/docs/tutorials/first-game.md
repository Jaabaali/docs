Go from an idea to a playable game in about two minutes. The example is a lane-based arcade game where a spelunker dodges monsters and bats underground.

<div class="video-embed"><iframe src="https://www.youtube-nocookie.com/embed/6ReO4TOuPrM" title="Video: Make your first game" loading="lazy" allow="accelerometer; clipboard-write; encrypted-media; gyroscope; picture-in-picture; web-share" referrerpolicy="strict-origin-when-cross-origin" allowfullscreen></iframe></div>

## Steps

1. [00:00](https://youtu.be/6ReO4TOuPrM?t=0) Click **Suggest an Idea** if you want Bali to propose a concept. Skip it if you already know what you want.
2. [00:12](https://youtu.be/6ReO4TOuPrM?t=12) Describe the game in a sentence: the genre, the setting, the player character and the goal.
3. [00:12](https://youtu.be/6ReO4TOuPrM?t=12) Choose 2D for tight, lane-style movement.
4. [00:32](https://youtu.be/6ReO4TOuPrM?t=32) Pick one of the templates Jabali recommends.
5. [00:38](https://youtu.be/6ReO4TOuPrM?t=38) Confirm. Bali starts generating assets and picks a title, synopsis and poster.
6. [00:46](https://youtu.be/6ReO4TOuPrM?t=46) Click **Finish with AI** to have Bali generate the full set of assets.
7. [00:59](https://youtu.be/6ReO4TOuPrM?t=59) Click any asset to preview it: the background, the poster and the player character.
8. [01:31](https://youtu.be/6ReO4TOuPrM?t=91) Open the game in **Preview** and playtest it.
9. [01:47](https://youtu.be/6ReO4TOuPrM?t=107) Ask Bali in the left panel for changes or new versions of assets.

:::note[Current app]
2D or 3D is now the **Camera** option under the prompt box, next to **Engine**. You can leave both on **Let Bali Decide**. See [Create your first game](/docs/studio/create-a-game/).
:::
