Open an existing lane-based arcade game and improve it by asking Bali in plain words. Part 1 changes visuals and adds a new enemy. Part 2 tunes movement and difficulty.

## Part 1: Change visuals and add an enemy

<div class="video-embed"><iframe src="https://www.youtube-nocookie.com/embed/Hg7U7JBunjo" title="Video: Customize a game, part 1" loading="lazy" allow="accelerometer; clipboard-write; encrypted-media; gyroscope; picture-in-picture; web-share" referrerpolicy="strict-origin-when-cross-origin" allowfullscreen></iframe></div>

1. [00:13](https://youtu.be/Hg7U7JBunjo?t=13) Ask for a visual change in plain words, such as making the title a brighter purple. Bali applies it and rebuilds the preview.
2. [00:35](https://youtu.be/Hg7U7JBunjo?t=35) Ask for something the template doesn't have, such as a pulsing title animation.
3. [01:24](https://youtu.be/Hg7U7JBunjo?t=84) Make the player 50% bigger. Bali finds every scene that uses the player and scales it.
4. [01:50](https://youtu.be/Hg7U7JBunjo?t=110) Ask Bali how the obstacles are set up, and compare its answer with the **Assets** tab.
5. [02:22](https://youtu.be/Hg7U7JBunjo?t=142) Regenerate an obstacle so it stands out more while matching the game's style.
6. [03:02](https://youtu.be/Hg7U7JBunjo?t=182) Ask which rows use that obstacle. Bali searches the whole project for you.
7. [03:48](https://youtu.be/Hg7U7JBunjo?t=228) Ask Bali to suggest a new creature that fits the theme and difficulty.
8. [04:24](https://youtu.be/Hg7U7JBunjo?t=264) In the asset generator, edit Bali's suggested prompt and generate the image with no background.
9. [05:00](https://youtu.be/Hg7U7JBunjo?t=300) Click **Done**. Bali wires the new asset into the game.
10. [05:34](https://youtu.be/Hg7U7JBunjo?t=334) Ask for a new movement pattern. Bali adds the script it needs.
11. [06:17](https://youtu.be/Hg7U7JBunjo?t=377) Tune speed, timing and intensity over a few rounds.

## Part 2: Refine, balance and polish

<div class="video-embed"><iframe src="https://www.youtube-nocookie.com/embed/q5EMnBps-4M" title="Video: Customize a game, part 2" loading="lazy" allow="accelerometer; clipboard-write; encrypted-media; gyroscope; picture-in-picture; web-share" referrerpolicy="strict-origin-when-cross-origin" allowfullscreen></iframe></div>

1. [00:00](https://youtu.be/q5EMnBps-4M?t=0) Play the game in **Preview**.
2. [00:22](https://youtu.be/q5EMnBps-4M?t=22) Fine-tune the enemy's movement and position with Bali.
3. [02:14](https://youtu.be/q5EMnBps-4M?t=134) Lower the difficulty: remove an obstacle from one row and slow an enemy down.
4. [03:45](https://youtu.be/q5EMnBps-4M?t=225) Make a loose request, like making the red tint behind the platforms more transparent. Bali works out which image you mean.
5. [06:40](https://youtu.be/q5EMnBps-4M?t=400) Bali changes the transparency without you digging through files.
6. [08:30](https://youtu.be/q5EMnBps-4M?t=510) Playtest, then publish.
