This path is for creators who have shipped a game in Studio or are comfortable reading code. It covers designing before you build, custom web and 3D projects, working in the code yourself, and extending Bali with your own tools.

The path follows the three project tutorials, about two hours of video, and adds the design advice from Jabali's masterclasses. Take the stages in order, or jump to the one you need.

:::tip[New to Studio?]
Start with the [Beginner path](/docs/start/beginner/). It covers the basics this path assumes.
:::

## Stage 1: Plan before you build

Settle the design first, so Bali has less to guess.

1. [Design and polish your game: settle the core first](/docs/studio/design-and-polish/#settle-the-core-of-your-game-first)
2. [Write prompts Bali can act on: plan the design first](/docs/studio/prompting/#plan-the-design-with-bali-before-it-builds)
3. [Attachments](/docs/studio/attachments/)
4. [Models and behavior](/docs/studio/models-and-behavior/)

**You can now** hand Bali a design document, pick the right model and behavior, and agree on a plan before any code is written.

## Stage 2: Go beyond templates

Start a game from an idea in a web engine, and keep its content in data files.

1. [Choose an engine](/docs/studio/engines/)
2. [Tutorial: Build a web game from scratch](/docs/tutorials/web-game-from-scratch/)

**You can now** start a Phaser game without a template and grow its content without touching the game logic.

## Stage 3: Work in the code

Find your way around a project, and fix things yourself when that's quicker.

1. [Studio interface: Layouts](/docs/studio/interface/#layouts) and [Scripts](/docs/studio/interface/#scripts)
2. [Tutorial: Fix and tune a Godot game](/docs/tutorials/fix-and-tune-a-godot-game/)
3. [Debug with Bali](/docs/studio/debugging/)

**You can now** find and fix a script by hand, rebuild and test, and give Bali the logs it needs.

## Stage 4: Build in 3D

Make a 3D game and fill it with textures, characters, a sky and cutscenes.

1. [Tutorial: Build a 3D game from scratch](/docs/tutorials/3d-game-from-scratch/)
2. [3D models and characters](/docs/studio/assets/3d-models/)
3. [Skyboxes](/docs/studio/assets/skyboxes/)
4. [Video](/docs/studio/assets/video/)

**You can now** start from a 3D template and add textures, rigged characters, a sky and cutscenes.

## Stage 5: Polish for players

Make the game clear and satisfying to play, and release it safely.

1. [Design levels that teach](/docs/studio/design-and-polish/#design-levels-that-teach)
2. [Polish: what playtesters notice](/docs/studio/design-and-polish/#polish-what-playtesters-notice)
3. [Place things precisely](/docs/studio/design-and-polish/#place-things-precisely)
4. [Version history](/docs/studio/version-history/)
5. [Publish your game](/docs/studio/publish/)

**You can now** design levels that teach, fix what playtesters notice, and release with restore points.

## Stage 6: Extend Bali

Give Bali standing rules, new know-how and access to your own tools.

1. [Project Instructions](/docs/studio/settings/#ai-settings)
2. [Agent Skills](/docs/studio/skills/)
3. [MCP servers](/docs/studio/mcp-servers/)
4. [Shell tool](/docs/studio/shell/)
5. [Godot plugins](/docs/studio/plugins/)

**You can now** give Bali rules for every request, teach it new workflows, connect outside tools and let it run project commands.
