When you enter a prompt, Jabali first creates a **game seed**: the foundational blueprint that guides how your game is generated. From the seed, Jabali creates a full **game concept** with a name, narrative summary, core mechanics and a poster image. You can edit or regenerate both to better match your vision.

## What is a game seed?

The game seed is the starting point for game generation: a structured set of values derived from your prompt. It keeps tone, theme and gameplay aligned across everything Jabali generates.

### What's in a game seed?

| Game type                | Game seed fields                                          |
| ------------------------ | --------------------------------------------------------- |
| **Character Simulation** | Character name, challenge, character bio, visual style    |
| **All other games**      | Visual style, game theme                                  |

### Example: character simulation game seed

```text
Character Name: Nova
Challenge: Keep her spaceship from falling apart while managing crew drama
Character Bio: A brilliant but emotionally detached engineer-cat navigating leadership
Visual Style: Cartoon sci-fi, pastel colors, side-view sprites
```

## What is a game concept?

Based on your seed, Jabali creates a **game concept**: a polished, high-level pitch for your game. It includes:

- **Game name**
- **Gameplay description:** mechanics, story loop or mission structure
- **Game poster:** an AI-generated visual for inspiration or use as a splash screen

### Example game concept

**Title:** Cogs of Solitude

**Description:** A narrative-driven resource management game where you play as Nova, a reclusive engineer-cat tasked with repairing a derelict starship. Each day, you balance repairs, morale and unexpected visitors, all while unraveling a hidden mystery.

**Poster:** An AI-generated image of Nova in a glowing engine room surrounded by floating toolbots.
