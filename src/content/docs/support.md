## Ask the community and the Jabali team

The best way to get support is the [Jabali Discord community](https://discord.gg/jabali). The Jabali team hangs out there, and other creators can help too.

## Report a bug in Jabali Studio

Click **Report** (the bug icon at the top of Bali's panel) in Jabali Studio to send a bug report or feedback on Bali's suggestions. Include what you expected, what happened and how to reproduce it. See [how to write a good bug report](/docs/studio/bali-best-practices/#be-descriptive-when-reporting-bugs).

## Check the FAQ

Many common questions are answered in the [Jabali Studio FAQ](/docs/studio/faq/).

## Report a problem with these docs

Found something wrong or out of date? [Open a docs issue on GitHub](https://github.com/Jaabaali/docs/issues/new/choose), or fix it yourself with the **Edit page** link at the bottom of any page. See [Contribute to the docs](/docs/contributing/).
